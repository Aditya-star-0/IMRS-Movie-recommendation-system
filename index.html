Welcome to Movie Recommendation System

Discover your next favorite movie with our intelligent recommendation system.

Features:

  • Similarity-based recommendations using TF-IDF and cosine similarity
  • Filter by actor, director, and genre
  • Continuous recommendations in batches of 5
  • Ranked by a weighted score (Rating * log(Votes))

To use the system, run the Streamlit app with: streamlit run app.py

Enter a movie name to get similar recommendations, optionally filter by actor, director, or genre.
